# Rascunho (extensão)

Overlay discreto para resolver questões do app enquanto você usa o Chrome.

## Instalar (descompactada)

1. Abra `chrome://extensions`
2. Ative **Modo do desenvolvedor**
3. **Carregar sem compactação** e escolha esta pasta `chrome-extension`
4. Faça login no site do app em alguma aba
5. Em qualquer outra aba, `Alt+Q` (ou o ícone da extensão)

O atalho pode ser alterado em `chrome://extensions/shortcuts`.

## Uso

- Arraste pela faixa superior
- `solto` some ~0,3s depois que o mouse sai; `fixo` permanece
- Clique na alternativa; duplo clique risca
- `1–5` seleciona, `Enter` envia (ou vai à seguinte), `I` inseguro, `C` chute, `N` nota, `Esc` fecha
- Fonte: caderno (lista) ou omissas
- Omissas: abra no site o link com `?t=` uma vez para a extensão guardar o token

A URL do app é detectada no login. Se não detectar, abra as opções da extensão e cole a URL.
